# GenDocsToc — Markdown ドキュメントの目次生成

Markdown ドキュメントに「## 目次」を生成・更新するスクリプト。

## 挿入位置

- 「## 変更履歴」セクションがあれば、その直後に挿入する。
- 「## 変更履歴」が無い場合は、「# タイトル」行の直後（最初の本文の前）に挿入する。

## 特徴

- **依存なし**（Python 標準ライブラリのみ。実行に venv は不要だが、本プロジェクトでは `Tools/.venv` を使う運用とする）
- 目次に含める見出しは `##`（H2）と `###`（H3）。`#`（タイトル）・`####` 以下は対象外
- 「## 変更履歴」「## 目次」自身は目次に含めない
- アンカーは GitHub(.com) 方式（小文字化・空白→ハイフン・記号除去・中点`・`除去）
- コードフェンス（``` ~~~）内の `#` 行は見出しとみなさない
- **冪等**：同じ内容なら再実行しても変化なし（`[NOCHANGE]`）
- 既存「## 目次」がある場合は **目次ブロックのみ** を置換（直後に `---` が無くても本文を巻き込まない）

## セットアップ（venv）

```bash
python3 -m venv Tools/.venv
# 標準ライブラリのみのため追加インストールは不要
```

## 使い方

```bash
# 1ファイル
Tools/.venv/bin/python Tools/GenDocsToc/gen_toc.py Docs/仕様-AgentNest全体.md

# 複数ファイル（glob 可）
Tools/.venv/bin/python Tools/GenDocsToc/gen_toc.py Docs/*.md

# 書き込まず結果だけ確認
Tools/.venv/bin/python Tools/GenDocsToc/gen_toc.py --dry-run Docs/*.md
```

## 出力ステータス

- `[inserted]` … 目次が無かったので新規挿入（変更履歴の後／無ければタイトル直後）
- `[regenerated]` … 既存の目次を作り直した
- `[NOCHANGE]` … すでに最新（変化なし）
- `[SKIP]` … 「# タイトル」見出しが見つからず処理しなかった

## 注意

- 見出しを追加・変更したら、本スクリプトを再実行して目次を追従させる
